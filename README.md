# M Avto Service — Полтава

Готовый адаптивный лендинг: оригинальный логотип, фоновое фото, анимации с кнопкой паузы, услуги, отзыв 2026 года, карточки выбора проблемы, стоимость по запросу, форма подготовки SMS и контакты с Google Maps.

## Запуск

Требуется Node.js 20 или новее. Установка зависимостей не нужна.

```sh
npm run build
npm start
```

Открыть http://localhost:3000. Папка `dist/` уже содержит готовый сайт; её можно разместить на статическом хостинге. Для Vercel добавлена конфигурация `vercel.json`.

## Редактирование по частям

- `src/layout.html` — каркас страницы и порядок секций.
- `src/sections/` — отдельные HTML-файлы: header, hero, services, reviews, concerns, steps, pricing, booking, contacts, footer.
- `src/styles/` — базовые стили и современное оформление.
- `src/scripts/` — меню, появление секций, выбор услуги, форма, анимации и аккордеоны.
- `public/assets/` — оригинальный логотип и обработанное фоновое фото.
- `scripts/build.mjs` — собирает части в единый статический сайт без внешних зависимостей.
- `dist/` — результат сборки. После изменений выполнить `npm run build` и сохранить обновлённый `dist` вместе с исходниками.

Секции собираются до публикации: страница не зависит от загрузки HTML-фрагментов через JavaScript.

## Форма и контент

Форма проверяет данные и подготавливает SMS на публичный номер сервиса +380951195333. Пользователь отправляет сообщение сам из приложения SMS. Автоматическая отправка в почту или CRM не подключена. Данные не сохраняются на сервере.

Подтверждённый числовой прайс за 2026 год отсутствует: стоимость указана по запросу. Отзыв приведён с автором, датой и ссылкой на оригинал. Фоновое изображение улучшено с помощью AI на основе фотографии сервиса. Отвергнутая фотогалерея не включена в страницу.

Источники и история решений: `CONTENT-NOTES.md`, `assets-sources.json`.
